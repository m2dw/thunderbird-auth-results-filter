__MSG_section_trusted_servers__

Your incoming mail server stamps each message with an Authentication-Results header that identifies itself by a server name (the authserv-id). Add that name here so this add-on knows which authentication results to use for scoring. Results from servers not on this list are ignored.

    __MSG_section_score_settings__

    Score thresholds are fixed: 0–49 normal, 50–99 review, 100+ high risk. The inputs below control how much each signal adds to or subtracts from a message's total score. Authentication scoring (Layer 1) only uses results from the trusted server names you configure in the Basic tab; results from unrecognised servers are ignored.

    Email authentication results (Layer 1)

    DMARC, SPF, and DKIM result scores. Only results from your trusted authentication servers (Basic tab) are used.

    Sender identity alignment (Layer 2)

    Scores for mismatches between the visible From address and the authenticated identity. These are evidence signals; their combined default (25) stays well below the Review threshold (50).

    Address pattern heuristics (Layer 3)

    Weak signals based on whether the From address looks machine-generated. These are evidence for Layer 4 rules. Keep these values low — the cap limits total Layer 3 contribution so it cannot push a message into Review on its own.

    Warning: the Layer 3 cap is at or above the Review threshold (50). Layer 3 heuristics alone could push a message into Review — this is outside the intended low-pass design.

    Combined signal rules (Layer 4)

    Rules that fire only when multiple independent signals converge. These are the primary Review/Junk drivers. Mitigation rules (negative scores) reduce false positives for known-good delivery patterns.

    __MSG_section_manual_whitelist__

    Whitelist entries reduce this add-on's spam score for matching senders. They do not authenticate the message or prove it is genuine — they lower the score to reduce false positives for senders you recognise.

    Range: 0 to −100. Default: −50. Use −100 to keep whitelisted senders below the Review threshold.

    __MSG_whitelist_none__

    AddressMatch

    __MSG_section_address_book_whitelist__

    When enabled, senders found in your Thunderbird address books receive a score reduction. This does not authenticate the message — it lowers the score to reduce false positives for known contacts.

    Enabling this feature will request access to your Thunderbird address books.

    Range: 0 to −100. Default: −50.

    __MSG_section_diagnostics__

    Diagnostics mode shows a detailed decision log with raw scores, score reasons, heuristic metrics, and export tools. This is intended for troubleshooting and tuning — not needed for day-to-day use.
